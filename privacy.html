隱私權政策

本政策適用於 Hermes Agent 個人 Google 整合。此工具由 Google 帳戶擁有人在其裝置上操作，不提供公開服務。

存取哪些資料，以及為何存取

依你同意的權限及指定任務，工具可存取 Gmail 郵件與標籤、日曆與行程、Drive 檔案、Google 文件與試算表、Tasks 與清單、聯絡人（唯讀），以及 YouTube 帳戶與頻道相關資料。資料僅用於執行你要求的功能，例如查找或整理資訊；有外部影響或會修改資料的操作須先取得確認。

儲存、處理與分享

Google API 由本機程式呼叫，OAuth 憑證及權杖保存在本機受限檔案中，不上傳到本站。本站不接收透過 Google API 取得的資料，不要求登入，也沒有表單或應用程式分析追蹤碼。GitHub Pages 作為網站主機，可能依其政策處理網站連線資訊。

本工具不出售 Google 使用者資料，不用於廣告或訓練通用 AI 模型，不會為了模型處理而自動轉送 Google 資料。若個別工作需要把 Google 資料交給其他服務處理，只有在 Google 政策允許、使用者知情同意、接收方符合資料保護要求，且限於交付該功能必要的資料時才會進行；無法滿足這些條件時不會轉送。使用者選擇保存的 API 輸出可能留存在本機檔案或工作紀錄。

撤銷授權與刪除本機資料

你可以在 Google 帳戶的第三方連線撤銷同意，停止本工具後續存取。撤銷不會移除先前儲存的本機檔案；你可自行移除本機權杖及已保留的輸出或工作紀錄。

Google API 資料政策

本應用程式對從 Google API 取得資訊的使用及轉移遵守 Google API Services User Data Policy，包括 Limited Use 要求。

This application's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
